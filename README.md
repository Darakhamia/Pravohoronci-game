# Предатель (рабочее название)

Онлайн-игра для своей компании: социальная дедукция плюс шутер на космостанции. 5–8 игроков, среди них 1–2 предателя, раунд 10–15 минут. Godot 4.7.2, GDScript, выделенный headless-сервер.

Правила проекта, архитектура, зоны ответственности и план — в [CLAUDE.md](CLAUDE.md).

## Что уже работает

- Лобби, старт матча хостом, раздача ролей (каждый знает только свою).
- Задания экипажа четырёх видов, общий прогресс, фальшивые задания предателя.
- Оружие: кулаки, пистолет со стоек, нож предателя. Урон по частям тела, конечности отлетают; без ноги игрок хромает, без обеих — ползёт.
- Саботаж реактора с обратным отсчётом, тревожная кнопка, сообщение о теле, собрание с голосованием и изгнанием.
- Победа экипажа или предателей, экран итогов, возврат в лобби. Мёртвые летают призраками.
- Карта «Станция»: кают-компания, семь помещений и кольцо коридоров.

## Что нужно

- **Godot 4.7.2-stable** (обычная сборка, не .NET): <https://godotengine.org/download/archive/4.7.2-stable/>. У всех должна быть одна и та же версия.
- Для запуска из консоли и тестов: `godot` в `PATH` или переменная окружения `GODOT` с путём к бинарнику.
- Только если хочешь заново сгенерировать модели и текстуры: Blender 4.0 и Python 3 с `numpy` и `Pillow`. Готовые файлы уже лежат в репозитории.

## Быстрый старт

1. Клонируй репозиторий и открой `project.godot` в редакторе (первый запуск импортирует ресурсы).
2. Запусти сервер из папки проекта:

   ```bash
   godot --headless --server --min-players=1
   ```

3. Запусти клиент (F5 в редакторе), введи имя и адрес `127.0.0.1`, нажми «Подключиться». Хост лобби (первый вошедший) жмёт «Старт».

Для настоящей игры нужно минимум 5 человек. Один игрок на сервере с `--min-players=1` может побегать по станции и поделать задания: предателей в таком матче нет.

### Управление

| Клавиша | Действие |
| --- | --- |
| WASD, мышь | движение и обзор |
| Пробел | прыжок (призраком — вверх) |
| E | действие: задание, кнопка, стойка с оружием, сообщить о теле. Часть действий нужно удерживать |
| Левая кнопка мыши | удар или выстрел |
| Q | сменить оружие (и бросить канистру) |
| F | саботаж (только предатель) |
| Esc | пауза, закрыть панель |

### Как идёт матч

1. Каждому показывают роль: экипаж или предатель.
2. Экипаж выполняет задания из своего списка. Предатель делает вид, что тоже занят, убивает без свидетелей и устраивает саботаж.
3. Нашёл тело или что-то заподозрил — созывай собрание: обсуждение идёт голосом (Discord), потом голосование. Набравшего больше всех голосов выбрасывают за борт.
4. Экипаж побеждает, когда сделаны все задания или не осталось предателей. Предатели — когда их не меньше, чем живого экипажа, или когда реактор не успели починить.

### Параметры запуска

| Параметр | Кому | Что делает |
| --- | --- | --- |
| `--server` | сервер | запуск выделенного сервера (вместе с `--headless`) |
| `--port=7777` | сервер | порт UDP, по умолчанию 7777 |
| `--min-players=N` | сервер | минимум игроков для старта (по умолчанию 5) |
| `--join=адрес[:порт]` | клиент | сразу подключиться к серверу, минуя меню |
| `--name=Ник` | клиент | имя для `--join` |

Для отладки и тестов у сервера есть ещё флаги:

| Параметр | Что делает |
| --- | --- |
| `--traitors=N` | сколько предателей раздать (по умолчанию — по правилам: с 3 игроков один, с 7 — двое) |
| `--traitor-name=Ник` | сделать этого игрока предателем; можно указать несколько раз |
| `--map=имя` | карта вместо основной: имя файла из `scenes/maps` или `tests/maps` без `.tscn` |
| `--set=свойство=значение` | переопределить число из `resources/game_config.tres`, например `--set=role_reveal_seconds=0` |
| `--director=res://путь.gd` | узел-помощник теста на сервере |

### Несколько клиентов из редактора

Debug → Customize Run Instances… → включи Enable Multiple Instances и задай аргументы экземплярам:
первому — `--server --min-players=1`, остальным — `--join=127.0.0.1 --name=Игрок2` и так далее.

### Запуск без редактора (сервер, CI, свежий клон)

Перед первым headless-запуском на свежем клоне один раз выполни импорт — без него движок не видит классы (`class_name`) и модели:

```bash
godot --headless --import
```

## Проверка перед pull request

```bash
./tests/run_tests.sh
```

Скрипт делает импорт, гоняет юнит-тесты, смоук-тест (сервер и два бота: лобби, матч, движение, выход) и сценарии: сервер и несколько ботов проходят куски матча — бой, задания, саботаж, собрания. Один сценарий запускается так:

```bash
tests/scenarios/run_scenario.sh meeting
```

Сценарии завязаны на время. Если машина сильно загружена и один из них упал, сначала перезапусти его отдельно.

На Windows запускай из Git Bash. В `GODOT` указывай основной exe (`Godot_v4.7.2-stable_win64.exe`), а не `*_console.exe`: иначе сервер теста может остаться висеть и занять порт.

## Модели, текстуры и шрифты

Всё, кроме шрифтов, сделано скриптами этого репозитория — покупных и скачанных моделей нет.

- Модели: `tools/assets/*.py` (Blender) → `assets/models/**/*.glb`.
- Карта: `python3 tools/maps/station.py` → `scenes/maps/station.tscn`.
- Тема интерфейса: `godot --headless -s res://scripts/ui/theme/build_theme.gd` → `resources/ui/theme.tres`.
- Шрифты Onest и Unbounded — сторонние, лицензия SIL OFL (тексты лицензий лежат рядом, в `assets/fonts/`).

Сцены предпросмотра для глаз — в `tests/visual/` (персонаж, набор станции, обход карты, экраны интерфейса).
