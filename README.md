# Предатель (рабочее название)

Онлайн-игра для своей компании: социальная дедукция плюс шутер. Godot 4.7.2, GDScript, выделенный headless-сервер.

Правила проекта, архитектура, зоны ответственности и план — в [CLAUDE.md](CLAUDE.md).

## Что нужно

- **Godot 4.7.2-stable** (обычная сборка, не .NET): <https://godotengine.org/download/archive/4.7.2-stable/>. У всех должна быть одна и та же версия.
- Для запуска из консоли и тестов: `godot` в `PATH` или переменная окружения `GODOT` с путём к бинарнику.

## Быстрый старт

1. Клонируй репозиторий и открой `project.godot` в редакторе (первый запуск импортирует ресурсы).
2. Запусти сервер из папки проекта:

   ```bash
   godot --headless --server --min-players=1
   ```

3. Запусти клиент (F5 в редакторе), введи имя и адрес `127.0.0.1`, нажми «Подключиться». Хост лобби (первый вошедший) жмёт «Старт».

Управление: WASD — движение, мышь — обзор, пробел — прыжок, Esc — пауза.

### Параметры запуска

| Параметр | Кому | Что делает |
| --- | --- | --- |
| `--server` | сервер | запуск выделенного сервера (вместе с `--headless`) |
| `--port=7777` | сервер | порт UDP, по умолчанию 7777 |
| `--min-players=N` | сервер | минимум игроков для старта (по умолчанию 5, для локальной проверки — 1 или 2) |
| `--join=адрес[:порт]` | клиент | сразу подключиться к серверу, минуя меню |
| `--name=Ник` | клиент | имя для `--join` |

### Несколько клиентов из редактора

Debug → Customize Run Instances… → включи Enable Multiple Instances и задай аргументы экземплярам:
первому — `--server --min-players=1`, остальным — `--join=127.0.0.1 --name=Игрок2` и так далее.

### Запуск без редактора (сервер, CI, свежий клон)

Перед первым headless-запуском на свежем клоне один раз выполни импорт — без него движок не видит классы (`class_name`):

```bash
godot --headless --import
```

## Проверка перед pull request

```bash
./tests/run_tests.sh
```

Скрипт делает импорт, гоняет юнит-тесты и смоук-тест: поднимает headless-сервер и двух ботов-клиентов, которые заходят в лобби, стартуют матч, по очереди ходят и прыгают и возвращаются в лобби.

На Windows запускай из Git Bash. В `GODOT` указывай основной exe (`Godot_v4.7.2-stable_win64.exe`), а не `*_console.exe`: иначе сервер теста может остаться висеть и занять порт.
